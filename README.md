# CostToken

Локальная аналитика токенов AI-агентов для macOS. Приложение читает журналы, которые агенты уже сохранили на этом Mac, показывает расход за день, 7 дней, 30 дней, 6 месяцев, год или всё время, разбивку по агентам и моделям, входные и выходные токены, чтение и запись кэша. Интерфейс обновляет данные раз в минуту.

## Время работы с AI

Обзор также показывает два счетчика часов за выбранный период и агента. **«Ваше время»** — оценка по отметкам ваших действий: действия одной сессии с паузой до 15 минут объединяются, к началу добавляется 1 минута, к концу — 2 минуты. Перекрывающиеся сессии разных агентов считаются один раз. **«Задачи агентов»** — суммарное календарное время задач по сохраненным журналам; перекрытия также не удваивают время. Если для агента нет надежных отметок длительности, интерфейс показывает «—».

Эти часы не являются точным учетом времени перед экраном: история может быть удалена, а задачи могут включать ожидание инструментов. Метод и ограничения описаны в [дизайне счетчика](docs/activity-time.md).

CostToken написан на Rust, React и TypeScript и упакован как приложение Tauri. Swift в проекте нет. На поддерживаемой macOS окно использует системный эффект Liquid Glass.

## Запуск

```bash
npm install
npm run tauri dev
```

Сборка приложения:

```bash
npm run tauri build -- --bundles app
```

Готовый файл находится в `src-tauri/target/release/bundle/macos/CostToken.app`.

## Откуда берутся данные

CostToken использует только локальные счетчики из журналов. Текст запросов и ответов, системные промпты и файлы авторизации в интерфейс не передаются. Первая версия поддерживает Claude Code, Codex, Gemini CLI, доступные локальные счетчики Grok, OpenCode и LocalCode. Статус каждого найденного агента показан на экране «Источники». Некоторые агенты, включая Antigravity, сохраняют историю в закрытом бинарном формате: приложение отмечает их присутствие, но не приписывает им вымышленные токены. «Вся история» означает всю **доступную локальную историю**; если агент удалил или ротировал старые журналы, восстановить их приложение не сможет.

## Как считается стоимость

Сумма — **оценка эквивалентной стоимости по публичным API-тарифам**, а не платеж по подписке. Входные токены без кэша, выходные, чтение кэша и запись кэша имеют отдельные ставки. Для Claude при доступном счетчике различаются 5-минутная и 1-часовая запись кэша. Если тариф модели неизвестен, токены остаются в аналитике, а ее стоимость помечается как неизвестная. Тариф можно задать локально на экране «Тарифы».

Для Codex новые журналы учитываются по записям отдельных запросов. В старых журналах CostToken берет `last_token_usage` только при изменении накопленного `total_token_usage` и пропускает начальный повтор истории родителя в дочерних сессиях. Накопленный счетчик новой сессии не считается новым расходом. Метод исправляет крупное завышение, которое возникало при ветвлении задач.

CostToken применяет встроенные стандартные тарифы для короткого контекста. Поэтому сумма может отличаться от [ccusage](https://ccusage.com/guide/cost-modes), который в режиме `auto` использует сохраненную стоимость, исторические тарифы и другие правила для длинного контекста. Кроме того, доступные источники двух программ могут различаться.

Каталог ставок проверен 27 сентября 2026 года по официальным страницам [Anthropic](https://platform.claude.com/docs/en/about-claude/pricing), [OpenAI](https://developers.openai.com/api/docs/pricing), [Google](https://ai.google.dev/gemini-api/docs/pricing) и [xAI](https://docs.x.ai/developers/pricing). Тарифы меняются; опубликованные ставки также могут зависеть от длины контекста, региона и режима выполнения. Стоимость инструментов, хранения кэша и дополнительных сервисов не входит в оценку.
