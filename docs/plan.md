# CostToken — план реализации

## 1. Каркас и данные

- Создать Tauri 2 + React/TypeScript проект в этой папке, окно `.app` с эффектом Liquid Glass и безопасным набором команд.
- В Rust реализовать потоковые адаптеры журналов Claude Code и Codex, затем других источников с подтвержденными счетчиками. Держать в памяти краткие итоги для каждого файла и заново читать только изменившиеся файлы.
- Возвращать в UI почасовые нормализованные суммы по агенту и модели, статусы источников и время обновления.

## 2. Аналитика и тарифы

- Вычислять диапазоны: день, неделя, месяц, 6 месяцев, год, всё время; группировать точки графика по масштабу периода.
- Встроить датированный каталог официальных тарифов, отдельные ставки для input/output/cache read/cache write; хранить пользовательские переопределения локально.
- Отдельно показывать модели без тарифов и API-оценку, не выдавая ее за платеж по подписке.

## 3. Интерфейс и запуск

- Собрать dashboard с адаптивной компоновкой, фильтром агентов, графиком, токенами, кэшем, состояниями источников и редактором ставок.
- Добавить состояния загрузки, пустой истории, ошибок чтения и снижение анимации по настройке системы.
- Запустить автоматические тесты, production-сборку, открыть `.app` на текущем Mac и проверить окно визуально.
