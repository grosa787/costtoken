# CostToken — дизайн приложения

Дата: 27 сентября 2026 года.

## Цель

Локальное приложение для macOS, которое показывает, сколько токенов использовали установленные AI-агенты, как распределилось использование по времени и какой была бы ориентировочная стоимость этих токенов по опубликованным API-тарифам. Главная задача: быстро понять расход за сегодня и за любой из периодов «неделя / месяц / 6 месяцев / год / всё время», увидеть вклад каждого агента и долю кэша.

## Платформа и приватность

- Tauri 2 с Rust для чтения локальных файлов и React/TypeScript в системном WebKit для интерфейса. Swift не используется.
- Только чтение локальных журналов. Приложение не считывает ключи и токены доступа, не загружает содержимое запросов в интерфейс и не отправляет данные на сервер.
- Окно использует системный `liquidGlassRegular` на поддерживаемой macOS и обычный системный материал на старых версиях. Анимация учитывает настройку Reduce Motion.
- Приложение собирается в `.app` и запускается на текущем Mac.

## Источники и точность

Первая версия читает истории Claude Code и Codex. Дополнительные адаптеры подключаются для найденных на этой машине журналов Gemini CLI, Antigravity, Grok и других агентов, если их файлы содержат надежные счетчики токенов. Если приложение обнаружило агент, но не нашло счетчиков, оно показывает этот статус явно и не выдумывает число.

Каждая запись нормализуется в: время, агент, модель, входные без кэша, выходные, чтение кэша, запись кэша, при наличии reasoning output. Сессии и промежуточные накопительные счетчики дедуплицируются. При следующих обновлениях переобрабатываются только изменившиеся файлы.

Стоимость вычисляется по тарифу модели за миллион токенов отдельно для входа, выхода, чтения и записи кэша. Неизвестный тариф не превращается в $0: для такой модели показываются токены и статус «тариф не найден». Сумма обозначается как оценка API-эквивалента, поскольку подписка, лимиты и фактический счет могут отличаться. Пользователь может задать или исправить тариф для модели локально.

## Интерфейс

Одна главная панель: период, сумма-оценка, общий объем токенов, распределение input/output/cache, график расхода, список агентов и моделей, и состояние найденных источников. Для выбранного дня график показывает часы; для недели и месяца — дни; для длинных периодов — недели или месяцы. Нажатие на агента фильтрует график и итоги. Панель тарифов дает редактировать четыре цены модели.

Визуальный язык: спокойная macOS-утилита с ровным фоном `#151E29`, текстом `#E6ECF1`, вторичным текстом `#95A7B6`, стальным синим `#9AB8CF` для графика и приглушенной зеленью `#9FBEAF` для кэша. Системный Liquid Glass остается материалом окна за боковой панелью; CSS-размытие не применяется. Кнопки имеют четкие границы и состояния. Шрифт SF Pro с табличными цифрами. Стоимость, график и таблицы имеют первенство над декором: нет рекламного заголовка, светящихся орбит и набора одинаковых карточек.

## Ошибки и проверка

Недоступные папки и поврежденные строки JSON не обрывают весь обзор: статус источника сообщает о проблеме, корректные записи остаются видимыми. Тесты проверяют нормализацию счетчиков, дедупликацию, периодизацию и расчет цены. Финальная проверка включает сборку, автоматические тесты, запуск `.app` и визуальный просмотр интерфейса на данных этого Mac.
